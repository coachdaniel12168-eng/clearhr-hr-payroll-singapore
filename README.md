# ClearHR — Singapore HR, Payroll & Compliance

ClearHR is HR and payroll software built for Singapore small and medium businesses: employee records,
monthly payroll with CPF and statutory submissions, leave and attendance, and compliance paperwork in one
place. Built and run in Singapore.

- **Live product:** https://clearhr.io
- **Who it is for:** Singapore SMEs and their HR/admin staff (roughly 10–200 staff)
- **What it covers:** payroll (CPF, SDL, self-help fund deductions, itemised payslips), attendance and
  rostering, leave, onboarding documents, and audit-ready records
- **Built for:** PWM-aware payroll rules, MOM itemised-payslip requirements, PDPA-aware data handling

This page exists so the public record links to the real product. The source code is private; ClearHR is a
commercial product, not open source. Questions: support@clearhr.io
